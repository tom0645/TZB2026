# 单批次顶点色模型

此目录由 `code/scripts/optimize_frontend_models.py` 从上一级自制 GLB 生成，原资源不变。

- 每个模型合并为一个三角形 primitive 和一个不透明白色材质，减少常态三维模型的绘制批次。
- 原部件的 `baseColorFactor` 转为 Float32 `COLOR_0`，保留深浅和识别色；统一粗糙度为 1、金属度为 0，减少反光。
- 顶点位置、三角形顺序、法线、包围范围和米制尺寸均保持不变；继续采用 glTF `+Y` 向上、`+X` 向前。
- `tree.glb` 仍高 12 米，无人机在场景中的海拔由前端决定。
- 无外部图片、纹理、骨骼、动画或联网依赖。`manifest.json` 记录优化前后批次数、大小和验证结果。

顶点色使文件体积略有增加；这里优化的是每帧 GPU 绘制调用，并没有通过删减模型细节冒充性能优化。
