# 三维态势预览模型

本目录模型由本项目的几何生成脚本制作，不引用外部模型或贴图。运行
`python code/scripts/build_frontend_models.py` 可重新生成，并校验 GLB 结构。

- 统一采用 glTF 2.0，单位为米，模型坐标 `+Y` 向上，`+X` 向前。
- `uav.glb`：四旋翼无人机，机身中部为原点，完整旋翼外廓约 2.26 米。
- `ugv.glb`：六轮无人车，含前摄像窗、灯、激光雷达和天线。
- `tree.glb`：地面底部为 0，树梢高度精确为 12 米。
- `person.glb`、`vehicle.glb`、`facility.glb`：人员、车辆与设施的简化模型。
- 地面模型底部为 `Y=0`；无人机在场景中的高度由地图渲染器设为 10 米。

这些是三维显示资源，不改变后端二维导航、任务完成或传感器判定。远景若
放大单位模型以便辨认，显示尺寸不代表它的真实外廓。每个模型的范围与三角形
数量见 `manifest.json`。
