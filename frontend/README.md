# TZB2026 Web 前端

## 本地终端与演习回放

双击 `desktop/start.cmd` 可打开独立本地应用窗口。推荐服务入口为 `web_server:app`：网络网关与仿真运行在不同进程，状态读取不等待规划结束。地图上方标签切换“实时推演 / 演习回放”：实时页自动记录，可命名保存；回放页支持时间条、前后 10 秒、事件定位及打开之前保存的文件。回放仅浏览历史，切回实时后从原现场继续。三维动态图层由 GPU 合成，高清地表纹理保持常驻。

操作流程、接口与实现边界见 [实时录制与演习回放](../docs/exercise-replay-guide.md)。

前端默认连接 `http://127.0.0.1:8000` 的仿真服务。服务启动后，页面上的运行、暂停、快进、场景切换、结束重置、任务注入、取消和优先级调整都会作用于真实的 Python `World`。

## 独立任务的协同规模

场景列表保留“人员搜救”“边境巡检”“区域封控”三个独立任务。新版网页后端在各自原场景内使用双倍平台：人员搜救为 8 架无人机、4 辆无人车；边境巡检为 8 架无人机、4 辆无人车；区域封控为 10 架无人机、4 辆无人车。平台分散在不同起始区域，协作完成各自任务，不把三类任务合并到同一个沙盘，也不复制待救援人员或其他目标。

顶部“协同规模 ×2”读取后端 `simulation.unit_scale`，地图副标题的区域尺寸与平台数量也来自实际快照。原有任务调度、发现后响应、资源占用和完成判定仍由 Python 后端处理。旧的混合大沙盘仅保留为历史代码，不再出现在场景选择入口中。

离线页面继续提供小规模本地预览，并明确标为本地演示；它不冒充后端双倍平台仿真。单位选择栏可用滚轮或左右按钮浏览更多平台，各场景切换时仍独立保留进度。

## 四倍速与长期运行

近期针对高倍近景切图增加 GPU 纹理复用和显存释放，先裁剪视野外路线；地图文字使用原生像素 HTML 覆盖层。区域封控首轮覆盖完成后继续外围巡查，敌机处置后落地并保持零速度。修复证据和边界见 [切图与持续警戒说明](../docs/map-freeze-and-area-patrol.md)。

运行节拍与三维绘制分离，四倍速每秒推进四个仿真步，浏览器按需绘制，运动动画最高 60 帧/秒。移动模型的高度引线与历史轨迹分别合批，历史线仅做误差不超过 0.75 米的显示简化；原始仿真轨迹不变。

网页使用 `/ws?compact=1` 接收变化字段，模型位置和任务变化及时推送，较大的历史轨迹与栅格最多每秒更新一次；原 `/ws` 全量接口继续兼容。连续到达的状态先合并，再在下一帧应用最新状态，避免积压。

决策事件仍保留当前会话的完整记录。界面先挂载最近 120 条，可点击“加载更早记录”逐批查看；新增事件复用已有行，避免长期运行后反复重建上千个对象。

双倍搜救的四辆无人车在救援结束后分别返回各自保障出发点，间隔两个仿真秒放行，避免同一步集中规划到地图角点、互相争用同一泊位。

## 三维预览

`3D` 分支默认进入本地 CesiumJS“外部视野”，可用地图上方的“卫星视野”按钮切回正上方的平面态势图。卫星视野是当前态势的俯视表达，未接入在线卫星影像。地面为海拔 0 米的平面，无人机显示海拔统一为 10 米；原地面障碍用雷区和湖泊表示，不再创建树模型。高度是前端显示约定，路径规划、任务判断和避障仍由后端二维仿真负责。

- 左键拖动平移，右键拖动旋转，滚轮缩放；地图上方也可点击加减按钮。
- 单击模型或左侧资产行查看详情并高亮，再次单击取消。
- 选中单位后点击“跟随”查看近景；跟随时左键拖动调整相对构图、右键拖动围绕单位旋转，均保留跟随状态和所选单位。点击“俯视”从上方观察，“全域”或定位按钮退出跟随并恢复总览。
- 选中友方单位后放大或进入跟随视角，深色信息框用浅蓝字显示海拔、速度、航向和电量。全域视角收起该信息框。友方无人机模型使用 `#03468A` 着色，无人车使用绿色。
- 入侵车辆、无人机模型使用 `#FF0303`，单击即可打开深底浅红字的信息框，再次点击取消。敌机处置后仍为红色，落地高度和速度均为 0。
- 覆盖/优先级/通行图、剩余规划路线、实际轨迹、任务和告警继续使用当前后端数据。
- 覆盖、优先级、通行图均支持再次单击取消显示。开启时使用纯栅格底图，不透出自然地表；取消后恢复自然地表和岸线。雷区颜色 `#D50066`，湖泊与沙盘外海平面均为 `#475869`；两者沿用后端地面禁行范围，无人机可飞越。三维显示网格每 100 米一格，仿真计算仍采用原有 50 米栅格。
- 三维地图在全域和近景中均使用标准大小的立体模型，统一 32 像素最小显示尺寸，移除大小选择；二维地图继续使用原有平面图标。
- 三维画面中的无人机固定以 35 倍高度显示，让全域和近景都可看见空地间距；相机缩放不会再动态调整高度。实际海拔仍为 10 米。
- 无人机高度引线连接至实际平面位置；轨迹和规划路径与模型使用相同的固定高度倍率。
- 自然地表底图由 2048×2048 多尺度纹理生成，在 Web Worker 中完成；选中数据图层时完全使用网格数据色，取消后恢复自然纹理。轨迹历史只在输入变化时简化，关闭轨迹跳过历史点处理；线索变化不重建静态几何，路线箭头按进度缓存并裁剪。
- 模型、轨迹与规划标记按单位复用；重复快照不重建整套图层，暂停后场景按需绘制。地图在负载高时仅作不低于 95% 的轻微分辨率调整，正常缩放保持接近原生分辨率。任务与指标面板按变化更新，单位点选即时响应。
- 单位轨迹使用最近 60 个仿真秒的渐隐尾迹，源端同步裁剪旧点，静止单位的旧轨迹也会过期。完整演习记录继续保存各帧位置。旋转、缩放时延迟历史几何及业务面板的刷新，模型运动和地图操作继续响应。
- 地图右侧「图层」按钮可控制规划路线、单位轨迹、目标轨迹和线索热源。开启状态使用淡青色边框和文字。
- 引擎和模型均位于本项目，正常使用不需要在线地图、Cesium ion 账号或额外 token。单个模型资源失败时只以位置标记替代；WebGL 上下文丢失会先尝试恢复，持续丢失时重建一次引擎，连续渲染失败才回退到卫星视野。
- 外部视野仅在持续帧率低于 28 FPS 时小幅降低绘制分辨率，并保持至少 95%；帧率恢复到 48 FPS 后逐步提高清晰度，不减少仿真单位或修改任务数据。

模型来源与坐标约定见 `assets/models/README.md`，依赖版本见 `vendor/README.md`。

## 视觉规范

界面使用深石墨底、蓝灰面板、细分隔线和线性图标，淡青色用于聚焦与选中。蓝色表示无人机，绿色表示无人车或正常状态，琥珀色表示注意事项，红色表示目标和高危告警。自然地表和网格降低对比度，实际轨迹使用实线，规划路线使用方向箭头。

## 界面控制说明

- 场景切换会暂停并保留原场景进度；再次切回时从原来的 Tick 继续。
- “结束 / 重置”只清空当前场景的进度、任务和事件记录，其他场景不受影响。
- 顶栏的快进按钮执行一次完整的 `World.tick()`，默认推进 1 秒。倍速独立控制连续运行时的速度。回放的前后 10 秒按钮位于地图下方时间轴。
- 自然语言到位、驻留指令未指定优先级时默认使用 65，先于常规搜索 70 执行；明确指定的优先级仍按指令保留。搜救和边境巡检会自动分配人工航点，保留正在处置或补能的平台，无人机完成任务或取消后恢复搜索/巡检。资源不足时，“决策与事件”会记录等待原因。
- 暂停时下达的任务在运行或快进后分配；仿真达到时长上限后，会拒绝新增任务并提示先结束重置。
- 鼠标停在地图上，滚轮向上放大、向下缩小，以鼠标所指位置为中心连续调整到 100%～400%；也可使用 `−`、`＋` 分档缩放。放大后按住左键拖动平移，准星按钮恢复全域视图。比例尺同步换算实际距离；`Ctrl + 滚轮` 保留浏览器的页面缩放功能。
- 坐标数字集中在地图边框外的左侧和底部刻度栏，随地图缩放、平移和窗口尺寸变化同步对齐网格，不遮挡边界附近的单位。
- 地图左上角显示沙盘区域。地图下沿显示比例尺、图例和当前底图，打开“图层”可切换数据底图及标绘。
- 左侧的资产、任务和告警共享导航栏。资产可按平台类型筛选，任务可按状态筛选。选中任务时，地图高亮关联平台及目标或坐标。新告警标出对应对象，点击告警可打开详情并定位。
- 告警队列与任务队列支持紧凑预览；收起后分别保留前 3 条告警和前 5 条任务，人工任务操作区不随任务列表收起。任务名称与状态下方按完整标签列出分配单位，多个标签自动换行，编号不会从中间断开；点击整行仍可查看任务详情。对象详情与调度记录中的“执行平台”沿用同一套单位标签。
- 人工注入的任务在名称前显示“小人图标＋人工”方形标记，涵盖表单和自然语言指令，完成或取消后仍保留。接口通过任务 `source` 字段区分 `manual` 和 `system`；自动生成的医疗后撤、返航等同名任务不会显示人工标记。前端兼容已有服务的人工调度与工具成功记录，刷新即可查看当前会话的标记。
- 右侧默认收起，通过对象选择或“事件记录”打开。事件记录按仿真时刻列出目标发现、任务变化、部署与分配、导航及模型操作，可查看全程、1 小时或 10 分钟。点击事件摘要可展开依据，点击定位可查看关联对象或跳到回放时刻。
- “复盘指标”集中显示任务评价与统计。右上角“人工注入”打开独立面板，支持从地图选点或选对象、提交结构化任务，以及核对原文后发送自然语言指令。演习回放中可通过“历史指令”查看当前时刻的记录。
- 顶栏「更多操作」提供保存回放、重置场景和调试工具。
- 三个地图图层均以“名称：颜色说明”显示图例，并与地图共用颜色映射。覆盖图由浅蓝（刚扫描）渐变到接近底色（至少 10 分钟未重扫或从未扫描）；优先级图由淡红色高值过渡到浅色低值；通行图区分绿色道路、灰色可通行地面和淡红色障碍。扫描时间按仿真时间计算，通行情况仅供无人车参考。

## 导航与新决策适配

- 规划箭头从平台当前位置连接前方尚未走过的路径点，随行进逐段缩短；到达或待命后不再显示旧规划箭头。后端完整规划数据仍保留供诊断使用，实际走过的路线由“单位轨迹”独立控制。
- 无人机路径与轨迹采用蓝色系，无人车采用灰绿色系；规划路径为密集 `>>` 方向箭头，实际轨迹为较浅的实线。单位卡默认四周均为细边框，选中时仅加粗上边框。地图同时显示禁飞区和临时障碍，图层由 40×40 细化至最高 100×100 格，仅调整显示采样，保留原有扫描范围和覆盖率计算。点击单位可查看导航状态、避让状态、剩余路程、预计用时及真实调度依据。
- “更多评价指标”按任务类型补充发现率、持续跟踪率、处置用时、换电与核心区防护等数据。边境覆盖率按巡检区域计算，与后端评价器保持一致。
- 左侧展开“导航与测试”，可建立独立的单平台绕障、双无人机交叉、双无人车交叉或空地交叉测试。支持设置目标与速度、模拟目标丢失、停止单位，以及新增、移动、移除临时障碍。退出后恢复原任务进度；测试中的重置只重置测试。
- 原始路径、前视点、安全间距和目标行为属于可选诊断显示。目标行为默认关闭，仅对已发现目标开放，不提前显示尚未发现的目标。

详细操作、新增接口及 UE 接入边界见 [网页导航测试与接口说明](../docs/web-navigation-guide.md)。

## 启动真实仿真

自然语言指令从项目根目录 `.env` 读取模型配置。首次配置可将 `.env.example` 复制为 `.env`，填写 `LLM_API_KEY`；DeepSeek 使用 `LLM_BASE_URL=https://api.deepseek.com`、`LLM_MODEL=deepseek-chat`。非空环境变量优先于文件，换终端、切换工作目录或重启服务后仍会读取这份本地文件。修改 `.env` 后下一条指令自动采用新配置，无需重启仿真；若终端已显式设置同名变量，则应先更新或移除该变量。

`.env` 已被 Git 忽略，且位于前端静态目录之外。“尚未配置大模型密钥”表示没有读取到值；“模型服务拒绝认证（401）”表示已经读取并发送密钥，但供应商不接受，需要核对密钥与服务地址。

```powershell
conda activate tzb2026
python -m pip install -r code\requirements.txt
python -m uvicorn web_server:app --app-dir code --host 127.0.0.1 --port 8000
```

然后打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。

服务提供：

- `GET /api/state`：当前结构化仿真状态
- `POST /api/session/run`、`pause`、`step`、`switch`、`reset`、`speed`
- `POST /api/tasks/inject`、`/api/tasks/cancel/{id}`、`/api/tasks/reprioritize/{id}`
- `POST /api/commands/llm`：执行自然语言指令，返回大模型决策摘要、工具调用与执行反馈
- `WS /ws`：每 250ms 推送一次状态快照

任务注入可选字段 `preferred_platform_type` 用 `uav` 限定无人机、用 `ugv` 限定无人车；`required_capabilities` 只表示所需能力，`sensor` 不能用来区分空中与地面平台。

## 仅预览界面

不启动 Python 仿真也可以运行本地演示：

```powershell
python -m http.server 4173
```

在 `frontend` 目录执行以上命令，然后打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。页面会使用本地回退数据，并在仿真服务可用后自动切换到 WebSocket 数据。

初始演示状态为零覆盖率、无已发现目标、无线索和告警，平台待命；点击运行或快进后才生成演示任务和后续事件。区域封控的演示空中目标分别在第 120 秒和第 900 秒出现。本地演示仅供界面预览，不替代真实仿真结果。

首次连接失败后会自动重试。接入真实仿真后若连接中断，页面保留最后同步的状态并暂停操作，重连后继续接收真实数据，不会切回本地演示推进。刷新页面不会重置后端已有进度；从头运行请使用“结束 / 重置”。
