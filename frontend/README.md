# TZB2026 Web 前端

前端默认连接 `http://127.0.0.1:8000` 的仿真服务。服务启动后，页面上的运行、暂停、单步、场景切换、结束重置、任务注入、取消和优先级调整都会作用于真实的 Python `World`。

## 视觉规范

界面采用现代作战指挥终端风格：灰黑半透明面板、1 像素分区线、方形控制件和紧凑数据排版。蓝色表示无人机与当前选择，绿色表示无人车或正常状态，琥珀色表示线索与注意事项，红色表示目标和高优先级告警。无人机和无人车使用带航向的俯视战术剪影；全域视图仅显示单位呼号，选中或放大后再显示任务与电量。圆形只用于在线状态、目标点和时间线节点等具有明确含义的标记。

## 界面控制说明

- 场景切换会暂停并保留原场景进度；再次切回时从原来的 Tick 继续。
- “结束 / 重置”只清空当前场景的进度、任务和事件记录，其他场景不受影响。
- “单步”执行一次完整的 `World.tick()`。默认推进 1 秒，并依次完成实体生成、控制决策、运动执行、态势感知、任务裁判、反应决策和状态推送；它不受当前倍速影响。
- 地图可通过 `−`、`＋` 调整到 100%～400%，放大后可按住地图拖拽平移；准星按钮恢复全域视图。
- 地图下方的单位栏列出全部无人机和无人车；点选卡片即可在右侧查看该平台的任务、电量、位置和能力信息。单位较多时可使用横向滚动条或标题右侧的左右按钮翻页。

## 启动真实仿真

```powershell
conda activate tzb2026
python -m pip install -r code\requirements.txt
python -m uvicorn web_api:app --app-dir code --host 127.0.0.1 --port 8000
```

然后打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。

服务提供：

- `GET /api/state`：当前结构化仿真状态
- `POST /api/session/run`、`pause`、`step`、`switch`、`reset`、`speed`
- `POST /api/tasks/inject`、`/api/tasks/cancel/{id}`、`/api/tasks/reprioritize/{id}`
- `WS /ws`：每 250ms 推送一次状态快照

## 仅预览界面

不启动 Python 仿真也可以运行本地演示：

```powershell
python -m http.server 4173
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，页面会使用本地回退数据，并在仿真服务可用后自动切换到 WebSocket 数据。
