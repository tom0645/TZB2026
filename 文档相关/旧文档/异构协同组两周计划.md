# 异构协同组两周任务计划（7.3-7.19）

## 1. 总体目标

本阶段以**边境巡检场景**为主线，优先完成异构协同组的最小闭环。

异构协同组当前闭环定义为：

```text
态势输入 → 任务生成 → 任务图构建 → 能力匹配 → 多目标评分 → 任务分配 → 指令输出 → 执行反馈 → 动态重规划
```

两周结束时，系统应能够完成以下展示：

```text
1. 读取边境巡检平台、任务、目标和事件输入；
2. 自动生成初始巡逻任务；
3. 发现异常目标后自动生成 identify / track / block / relay 任务链；
4. 根据平台能力、电量、状态和任务需求完成任务分配；
5. 输出任务分配结果、控制指令、决策日志和基础指标；
6. 在电量不足、目标逃逸、新目标出现时触发动态重规划；
7. 对比固定规则、最近距离优先、多目标评分分配三类策略。
```

## 3. 文件说明

### 3.1 核心运行文件

| 文件 | 作用 | 说明 |
|---|---|---|
| `demo_border_loop.py` | Demo 入口文件 | 用于一键运行边境巡检闭环，依次展示初始巡逻、异常目标出现、协同处置和动态重规划。 |
| `decision_system.py` | 决策系统主控文件 | 负责读取输入、调用任务图模块、调用分配算法、触发重规划、生成输出。是异构协同模块的主流程文件。 |
| `sample_input.json` | 样例输入文件 | 用于模拟态势层或 UE 输入，包括平台状态、初始任务、目标状态、异常事件等。 |
| `sample_output.json` | 样例输出文件 | 保存系统输出的任务分配结果、控制指令、决策解释和指标结果。 |

### 3.2 任务图与重规划文件

| 文件 | 作用 | 说明 |
|---|---|---|
| `task_graph.py` | 任务图模块 | 负责生成初始巡逻任务、异常目标处置任务，并维护任务依赖关系，例如 `track` 依赖 `identify`，`block` 依赖 `track`。 |
| `replanner.py` | 动态重规划模块 | 负责处理电量不足、目标逃逸、新目标出现等事件，重新调整任务图和任务分配。 |

### 3.3 分配算法文件

| 文件 | 作用 | 说明 |
|---|---|---|
| `allocator.py` | 任务分配模块 | 根据任务需求和平台状态，完成任务—平台匹配，输出 `assignments`。 |
| `cost_model.py` | 多目标评分模块 | 计算平台执行某任务的综合代价，考虑时间、电量、通信、风险、负载等因素。 |
| `compare_algorithms.py` | 算法对比模块 | 对比固定规则分配、最近距离优先、多目标评分分配三类策略，用于支撑汇报中的算法先进性说明。 |

### 3.4 输出与汇报文件

| 文件 | 作用 | 说明 |
|---|---|---|
| `decision_log.json` | 决策日志文件 | 自动记录每次任务分配的候选平台、最终选择平台和分配原因，用于体现可解释性。 |
| `metrics.json` | 指标统计文件 | 自动记录规划耗时、已分配任务数、未分配任务数、重规划次数、预计响应时间、预计能耗等指标。 |

## 7. 模块接口约定（V0 冻结版）

本节用于约定 A、B、C 三人并行开发时的模块调用方式。各模块内部实现可以独立调整，但函数名、参数和返回字段不应单方面修改。如确需修改，由三人确认后同步更新本节与 `sample_input.json`。

### 7.1 通用约定

```text
1. 距离和坐标统一使用米，字段名以 _m 结尾。
2. 速度统一使用米/秒，字段名以 _mps 结尾。
3. 时间统一使用秒，字段名以 _s 结尾。
4. 电量统一使用百分比，字段名为 battery_pct。
5. priority 数值越小，任务优先级越高。
6. 每个平台同一时刻最多执行一个主任务。
7. required_capability 必须是平台 capabilities 的子集。
8. B、C 模块只接收 Python 字典或列表并返回结果，不直接读写 JSON 文件。
9. JSON 文件读取、结果汇总和文件输出统一由 A 负责。
```

平台状态统一使用：

```text
idle / busy / offline / fault
```

任务状态统一使用：

```text
pending / assigned / running / completed / suspended / failed / cancelled
```

### 7.2 通用数据格式

平台数据沿用 `sample_input.json` 中 `platforms` 的格式：

```python
platform = {
    "platform_id": "FW_UAV_1",
    "type": "fixed_wing_uav",
    "position_m": [1000, 2000],
    "speed_mps": 25.0,
    "battery_pct": 45.0,
    "status": "idle",
    "current_task_id": None,
    "capabilities": ["sensor", "wide_area_recon", "track", "relay"]
}
```

任务数据沿用 `sample_input.json` 中 `initial_tasks` 的格式。事件任务中不适用的 `area` 或 `target_id` 使用 `None`：

```python
task = {
    "task_id": "T_patrol_border_01",
    "task_type": "patrol",
    "area": "border_line",
    "target_id": None,
    "target_position_m": [6000, 11000],
    "priority": 3,
    "required_capability": ["wide_area_recon"],
    "required_platform_num": 1,
    "predecessors": [],
    "deadline_s": 7200,
    "preemptible": True,
    "status": "pending"
}
```

事件数据沿用 `sample_input.json` 中 `events` 的格式：

```python
event = {
    "event_id": "E_intruder_detected_01",
    "event_type": "intruder_detected",
    "time_s": 120,
    "source": "fixed_sensor_01",
    "payload": {
        "target_id": "intruder_01",
        "position_m": [8500, 6000],
        "velocity_mps": [1.2, -0.3],
        "confidence": 0.85
    }
}
```

```text
1. battery_low：暂停受影响平台的原任务，并生成 return 或 charge 任务。

3. new_intruder_detected：插入新目标对应的任务链。
4. replanner.py 只更新任务，不选择接替平台，不返回 assignments。
```

### 7.6 C：任务分配接口

`allocator.py` 对外提供一个函数：

```python
def allocate(tasks, platforms):
    """完成能力过滤和任务分配，返回分配结果列表。"""
    return assignments
```

返回格式固定为：

```python
assignments = [
    {
        "task_id": "T_patrol_border_01",
        "platform_ids": ["FW_UAV_1"],
        "reason": "满足能力约束且综合代价最低",
        "cost": {
            "time_cost": 0.0,
            "energy_cost": 0.0,
            "communication_cost": 0.0,
            "load_cost": 0.0,
            "total_cost": 0.0
        }
    }
]
```

接口要求：

```text
1. 先过滤能力不匹配、电量不足、offline 和 fault 平台。
2. assignments 中每个 task_id 最多出现一次。
3. platform_ids 数量满足 required_platform_num。
4. 没有可用平台时，该任务不写入 assignments，由 A 根据任务列表识别未分配任务。
5. allocator.py 不生成控制指令，不写决策日志和指标文件。
```
