# 实时录制与演习回放

## 操作

启动 `desktop/start.cmd` 或 `web_server:app`，访问 <http://127.0.0.1:8000/>。

1. 点击“运行”，后台实时推演，同时自动记录从初始状态开始的过程。无需选择模式，也不提前计算未来。
2. 在地图上方的“实时推演”页点击“保存回放”，填写回放名称后保存 JSON。运行中和暂停后都能保存已发生的过程；窗口中的 `.json` 后缀会自动补齐。
3. 点击同一位置的“演习回放”标签，暂停现场并浏览已录制记录。该页仅显示打开文件、时间条、倒带和快进操作；拖动时间条或点击“−10 秒”“＋10 秒”定位，顶部播放、暂停、倍速和快进控制回放。
4. 回放中，“综合决策记录”默认展示全程事件。点击时间下方的“定位”，会跳到事件时刻、暂停播放并高亮展开该事件。回到早期时刻后，后面的事件仍可查看和定位。较多记录分批加载。
5. 点击“实时推演”标签回到原现场的最新时刻，保持暂停；点击“运行”继续演习。回放中的拖动不会回滚或改变现场。
6. 在“演习回放”页点击“打开回放”加载以前导出的 JSON 文件；退出后仍返回当前现场。即使还没有运行，也能切到该页打开文件。单文件最大 128 MiB，文件只包含公开态势，不导入可执行检查点。

回放只供复盘，人工指令、任务修改和结束重置在回放期间不可用。需要干预时先返回实时。记录默认保存在服务会话内，结束重置或关闭服务之前请先保存文件。

## 地图显示

- 原“林区”显示为雷区，使用 30% 强度的 `#D50066` 半透明填充；原“河谷”显示为湖泊，自然底图颜色 `#475869`，与沙盘外海平面一致。区域名称使用白色粗字，固定在区域中心。
- 雷区与湖泊仍使用原后端地面障碍范围，无人车绕行，无人机可飞越；不增加禁飞区，也不再创建树模型。
- 开启覆盖、优先级或通行图时，使用网格数据底图，隐藏自然地表颜色、道路与海岸装饰；再次点击取消后恢复自然底图。
- 全部三维单位固定采用标准大小，移除“较大”和模型大小控件。跟随、海拔显示、选择框及单位颜色保留。
- 地图上的 UAV/UGV 编号采用粗体、紧贴模型显示，三维中带紧凑深色底框。编号不附加海拔；对象详情窗口仍提供海拔、速度、航向和电量。
- 入侵车辆和无人机的三维模型统一采用 `#FF0303`。单击即可显示白底红字的信息窗口，再次单击取消选择；友方信息窗口继续使用白底蓝字。
- 单位轨迹仅保留最近 60 个仿真秒，较早部分逐渐淡出，超过窗口即移除。四倍速下相当于约 15 秒实际播放时间；暂停时不消退。完整回放仍逐帧保留单位位置，各历史时刻显示该时刻的近期尾迹。
- 三维显示高度固定为 ×35，移除倍率选择控件；相机缩放不会重算高度比例。无人机真实海拔数据仍为 10 米。
- 连续旋转、平移和缩放期间，模型位置保持更新；高度倍率固定为 35，避免每次镜头变化都重算高度及重建历史几何。

## 实现与接口

原 HTTP/WebSocket 网关、独立仿真进程和 GPU 图层缓存继续使用。实时录制复用已经产生的态势快照，超过 8 MiB 的压缩内容自动落盘；时间索引和当前解压帧另占少量内存。演习回放只移动记录游标，不运行 World 或重新调用模型。

| 接口 | 功能 |
| --- | --- |
| `POST /api/replay/enter` | 暂停现场，进入当前记录的演习回放 |
| `POST /api/replay/exit` | 返回原实时现场，保持暂停 |
| `POST /api/replay/seek` | 参数 `time`，定位记录范围内时刻 |
| `GET /api/replay/events` | 整场已录制的事件与模型执行记录 |
| `GET /api/replay/export?filename=名称.json` | 以指定名称下载演习 JSON，界面保存入口位于实时推演页 |
| `POST /api/replay/load` | 参数 `{archive: JSON}`，校验并加载已保存记录 |
| `GET /api/replay/status` | 记录终点、播放位置和模式 |

`replay.mode` 为 `live` 或 `exercise`；`recorded_until` 为已记录终点。`generation` 和 `simulation.state_revision` 防止旧状态覆盖跳转后的画面。旧 `/api/replay/config` 仅为历史接口兼容保留，当前界面不调用。

```powershell
python -m pytest -q code/test_web_exercise.py code/test_web_replay.py code/test_web_process.py code/test_web_stream.py
node code/scripts/check_frontend_replay.cjs
node code/scripts/check_frontend_3d.cjs

```

浏览器回归使用固定 API/WS 数据，不修改当前现场。`check_replay_integration.cjs` 是真实服务联调，仅允许本机的初始暂停测试场景，且必须显式设置 `TZB_ALLOW_SIMULATION_MUTATION=1`；它会推进并重置测试会话。
